# RPG Platform

Repository di infrastruttura e documentazione della piattaforma RPG.

## Repository

La piattaforma è suddivisa in tre repository:

- `rpg-platform`: infrastruttura, configurazione e documentazione
- `rpg-backend`: backend NestJS
- `rpg-frontend`: client Expo / React Native

## Documentazione

Tutta la documentazione testuale è scritta in Markdown.

I diagrammi sono definiti tramite PlantUML e versionati come file `.puml`.

## Architettura

La piattaforma utilizza:

- React Native / Expo
- NestJS
- PostgreSQL
- Keycloak
- object storage S3-compatible
- Docker / Docker Compose
